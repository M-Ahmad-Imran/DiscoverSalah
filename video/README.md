## Historical admin dashboard guide

`DiscoverSalah-Admin-Guide.mp4` is generated by `create_admin_video.py` from `admin-story.json` and `admin-assets/`. It uses Urdu narration with familiar English terms, English captions, Roman Urdu action headings, animated focus highlights and smooth scene transitions. `Admin-Guide-English.srt`, `Admin-Guide-Script.md` and `Admin-Guide-Chapters.txt` accompany the video.

The guide covers login/MFA, areas, focal accounts, the separate focal-person workflow for representative accounts, mosque registration, assignments and backup coverage, reviews, reports, suggestions, applications, notices/posters, maintenance, duplicates, notification delivery, history and account security. The app's authority rules remain explicit: administrators create focal accounts; the responsible focal person creates representative accounts; authors cannot approve their own submissions.

Screens are captured by `backend/scripts/media/capture-admin.ts` against an isolated temporary database. All people, phone numbers, passwords, mosque records and verification evidence are training examples. The image demonstration uses temporary local storage, not a real Cloudinary account. The capture does not read production credentials.

To reproduce, run the capture from `backend/` using `node node_modules/tsx/dist/cli.mjs scripts/media/capture-admin.ts`, then run `python video/create_admin_video.py --speech` and `python video/create_admin_video.py --render` from the project root. Speech generation uses the same free Edge TTS service as earlier guides and requires internet access. Set `TEMP`/`TMP` to a spacious temporary directory for the capture, and optionally set `DISCOVERSALAH_VIDEO_TEMP` for intermediate WAV files. Final deliverables stay in `video/`.

Python bytecode caches, capture console logs and individual MP4 segments in `assets/` are disposable. The generator recreates the segments when producing the final video. Do not remove source narration or screenshots merely because they are not imported by the web application.
