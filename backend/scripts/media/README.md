# Historical capture recipes

These capture scripts produced the original role guides under the earlier timetable-approval workflow. They remain reference material, but should not be used to generate current training against the new direct-publishing application.

The current workflow captures are maintained in `../browser-smoke.ts`, using isolated synthetic MongoDB and Playwright. The current renderer and narration source are `../../../video/create_workflow_v2.py` and `../../../video/workflow-v2-story.json`.

Old recordings and capture sources are preserved; their timetable approval instructions are superseded. To reproduce an old edition exactly, use the matching historical application revision as well as its capture recipe.
